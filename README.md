# LeadFlow CRM – AI Powered CRM Dashboard

An AI-powered full-stack CRM dashboard built using Next.js, MongoDB, NextAuth, and Gemini AI for intelligent lead management, analytics, and workflow automation.

---

## 🚀 Features

- Secure Admin Authentication
- Lead Management System
- Create, Edit, and Track Leads
- AI Credit Tracking System
- Dynamic Reports & Analytics
- Follow-Up Scheduling
- Dashboard Insights
- Responsive SaaS UI
- Dark Glassmorphism Design
- MongoDB Data Persistence
- Gemini AI Integration
- Functional Date Filters
- Reusable Navigation System

---

## 🛠️ Tech Stack

### Frontend
- Next.js 15
- React 19
- Tailwind CSS
- Framer Motion
- TypeScript

### Backend
- Next.js API Routes
- MongoDB
- Mongoose
- NextAuth

### AI Integration
- Gemini AI
- Genkit
