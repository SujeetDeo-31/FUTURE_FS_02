# **App Name**: LeadFlow CRM

## Core Features:

- Intelligent Pipeline Dashboard: Visual overview of lead sources, conversion charts, and priority status cards using real-time MongoDB data.
- Dynamic Lead Management: Comprehensive CRUD for leads with custom filtering by status, priority, and source, plus sorting capabilities.
- AI Next-Action Tool: A generative AI tool that analyzes lead interaction history to suggest the best personalized next step or response strategy.
- Unified Activity Timeline: An automated audit trail capturing every status change, note entry, and contact attempt in a sleek chronological feed.
- Automated Follow-up Scheduler: Integrated system for tracking next actions and follow-up dates to ensure zero lead leakage.
- Source Analytics Suite: High-fidelity reporting on monthly growth, source performance, and conversion trends via MongoDB aggregation.
- Admin Auth Guard: Secure single-user admin authentication for private CRM management and lead data protection.

## Style Guidelines:

- The palette is anchored by 'Digital Momentum'. The primary color is a deep, high-saturation Electric Indigo (#7c3aed).
- Background uses a dark, premium Midnight Obsidian (#09090b) to create high contrast for dashboard elements.
- The accent color is a soft Orchid Violet (#d8b4fe), providing visual hierarchy and emphasis on call-to-action buttons.
- Font pairing: 'Space Grotesk' (sans-serif) for headlines to provide a high-tech, precision feel, and 'Inter' (sans-serif) for body text and lead tables for maximum clarity.
- Thin-stroke minimalist line icons with soft glow effects to align with the modern dark SaaS aesthetic.
- Fixed sidebar navigation for high productivity with modular grid cards for the main content areas.
- Utilize Framer Motion for subtle entry transitions and spring-based physics for layout shifts between lead statuses.
